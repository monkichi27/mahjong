# ไพ่นกกระจอก จับ 3 (Mahjong Match 3)

เกมจับคู่ไพ่นกกระจอก 3 ใบ สำหรับเล่นบนมือถือ **ไม่มีโฆษณา ไม่เก็บข้อมูล เล่นออฟไลน์ได้**
ทำเลียนแบบเกมแนว "Tile Match / Mahjong Blast" แต่เขียนเองทั้งหมดด้วย HTML + CSS + JavaScript ล้วน ไม่ต้อง build

## วิธีเล่น
- แตะไพ่ที่ **ไม่มีไพ่ทับอยู่** (ไพ่ที่ถูกทับจะเป็นสีเข้ม) ไพ่จะลงไปในถาดด้านล่าง
- ไพ่เหมือนกันครบ **3 ใบ** ในถาดจะหายไป
- ถ้าถาดเต็ม **7 ใบ** โดยไม่มีคู่ = แพ้ (มีตัวช่วยกู้สถานการณ์ได้)
- ตัวช่วยต่อด่าน: ย้อนกลับ 5 ครั้ง, สลับไพ่ 3 ครั้ง, นำออก 3 ใบ 3 ครั้ง (ตั้งแต่ด่าน 20 จะค่อย ๆ ลดลง ต่ำสุด 2/1/1)
- **ไม่มีด่านสุดท้าย** เล่นได้เรื่อย ๆ ความยากไต่ขึ้นเรื่อย ๆ: จำนวนไพ่ถึง 150 ใบ (ด่าน ~22), ชั้นไพ่ถึง 7 ชั้น (ด่าน ~21), ชนิดไพ่ถึง 20 ชนิด (ด่าน ~46 ชนิดหลัง ๆ หน้าตาคล้ายกัน แยกยากขึ้น)
- ทุกด่านสุ่มใหม่และ **รับประกันว่าแก้ได้** (สร้างด่านด้วยวิธี reverse-solve)
- ความคืบหน้าบันทึกในเครื่องอัตโนมัติ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเกม |
| `style.css` | สไตล์ (mobile-first, รองรับแนวนอน/notch) |
| `game.js` | ตรรกะเกม, สร้างด่าน, วาดหน้าไพ่ (SVG), เสียง (WebAudio) |
| `sw.js` | Service worker ให้เล่นออฟไลน์ได้ |
| `manifest.webmanifest`, `icons/` | ทำให้ "เพิ่มไปยังหน้าจอโฮม" ได้เหมือนแอป |

## ทดลองเล่นบนเครื่อง
```bash
cd mahjong
python3 -m http.server 8123
# เปิด http://localhost:8123 (หรือ http://<IP เครื่อง>:8123 จากมือถือใน Wi-Fi เดียวกัน)
```

## นำขึ้นเว็บให้พ่อแม่เล่น (เลือกทางใดทางหนึ่ง)
ไฟล์ทั้งหมดเป็น static จึงวางบนบริการฟรีได้ทันที:

1. **Vercel** – `npm i -g vercel` แล้วรัน `vercel --prod` ในโฟลเดอร์นี้ (หรือลากโฟลเดอร์ไปวางที่ vercel.com/new)
2. **GitHub Pages** – push ขึ้น GitHub แล้วเปิด Settings → Pages → Branch `main` / root
3. **Netlify Drop** – ลากโฟลเดอร์ไปวางที่ app.netlify.com/drop

หลังได้ลิงก์แล้ว บนมือถือ:
- **iPhone**: เปิดใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android**: เปิดใน Chrome → เมนู ⋮ → "เพิ่มไปยังหน้าจอหลัก" / "ติดตั้งแอป"

## เมื่อแก้โค้ดแล้วอัปเดต
เปลี่ยนเลขเวอร์ชันใน `sw.js` (`const CACHE = 'mj3-v1'` → `v2`) เพื่อให้เครื่องที่เคยโหลดแล้วได้ไฟล์ใหม่

## ปรับความยาก
แก้ฟังก์ชัน `levelParams()` และ `helpersFor()` ใน `game.js` (จำนวนไพ่ / ชนิดไพ่ / ชั้น / จำนวนตัวช่วย ต่อด่าน)
